# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to
**customercare@hunterx.co.in** with "Security" in the subject line.

**Do not open a public GitHub issue, pull request or discussion for a
security report.** Public reports put users at risk before a fix is
available.

## What to include

- A description of the vulnerability and its impact
- The affected URL(s), page or file
- Steps to reproduce, or a proof of concept
- Your browser, device and any other relevant setup
- Whether you would like to be credited, and how

Please do not access, change or delete other people's data, run automated
scans that degrade the service, or use social engineering while testing.

## What to expect

- We aim to acknowledge reports within 3 working days.
- We will keep you informed while we investigate and fix the issue.
- We ask that you give us reasonable time to fix the issue before any
  public disclosure.

## Scope

This repository covers the HunterX website (https://hunterx.co.in). Issues
in the mobile app or API can be reported to the same address.
